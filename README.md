# 산업조직론 과제물1: 산업연관표 분석 웹앱

## 1. 프로젝트 소개
본 프로젝트는 2023년 산업연관표를 활용하여 산업 간 거래관계를 확인하고, 특정 산업의 최종수요 증가가 다른 산업에 미치는 경제적 파급효과를 분석하는 웹앱이다.

GitHub Pages를 통해 웹사이트를 배포하였으며, 웹브라우저에서 산업연관표 탐색과 수요충격 시뮬레이션을 수행할 수 있도록 구성하였다.

## 2. 웹사이트 주소
https://sungeun1216.github.io/webappTitle/

## 3. 주요 기능
- 2023년 산업연관표 원자료 탐색
- 대분류 33개, 중분류 83개, 소분류 165개, 기본부문 380개 산업 조회 및 분석
- 12개 원자료 시트 선택 및 탐색
- 산업명과 산업코드를 이용한 검색
- 최종수요 증가에 따른 생산·수입·부가가치 파급효과 분석
- 산업별 분석 결과 CSV 다운로드 기능

## 4. 웹앱 사용 방법
1. 웹사이트에 접속한다.
2. 대분류·중분류·소분류·기본부문 중 원하는 산업분류를 선택하고 '선택한 분류 불러오기' 버튼을 클릭한다.
3. 분석하려는 시트를 선택한다.
4. 산업명이나 코드를 검색하여 산업별 데이터를 확인한다.
5. 시뮬레이터에서 분석 대상 산업을 선택한다.
6. 최종수요 증가액을 백만원 단위로 입력한다.
7. '시나리오에 추가' 버튼을 클릭한다.
8. '파급효과 계산' 버튼을 클릭하여 결과를 확인한다.
9. 필요한 경우 분석 결과를 CSV 파일로 다운로드한다.

## 5. 산업연관분석 방법
산업연관분석은 산업 간 재화와 서비스의 투입 및 산출 관계를 바탕으로 경제적 파급효과를 분석하는 방법이다.

특정 산업의 최종수요가 증가하면 해당 산업뿐만 아니라 중간재를 공급하는 다른 산업의 생산에도 영향을 미친다.

본 웹앱에서는 투입계수와 레온티에프 역행렬을 활용하여 최종수요 증가에 따른 생산유발효과를 계산한다.

또한 생산 증가에 따른 수입유발효과와 부가가치유발효과를 분석하여 산업 간 경제적 연관관계를 파악한다.

## 6. 분석 자료 및 단위
- 분석 기준연도: 2023년
- 가격 기준: 생산자가격
- 현재 분석 대상: 대분류·중분류·소분류·기본부문
- 금액 단위: 백만원
- 최종수요 증가액: 백만원 단위로 입력
- 투입계수 및 유발계수: 금액과 구분하여 해석

## 7. 기대 효과
산업별 최종수요 증가가 전체 경제에 미치는 영향을 정량적으로 분석할 수 있다.

또한 산업 간 생산 및 거래관계를 이해하고, 특정 산업에 대한 수요 변화가 다른 산업에 미치는 영향을 비교하는 데 활용할 수 있다.
